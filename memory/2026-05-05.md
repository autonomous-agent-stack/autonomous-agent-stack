- The v2 console now has a natural-language Butler form for previewing routes and creating tasks without manual capability selection.
- Focused validation passed with `uv run --no-project --with-requirements requirements.txt pytest tests/test_control_plane_v2.py tests/test_butler_router.py` and local `ruff check`.

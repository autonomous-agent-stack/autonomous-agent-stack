# CrewAI 演示 agent / CrewAI demo agent

中文：`aas_crewai_demo` 展示 CrewAI-style 代码如何接入 AAS runner。CrewAI 负责写 agent 逻辑，AAS 负责隔离运行、路径策略、验证、promotion gate 与审计输出。

English: `aas_crewai_demo` shows how CrewAI-style code plugs into the AAS runner. CrewAI owns the agent logic while AAS owns isolated execution, path policy, validation, the promotion gate, and audit output.

```bash
make crewai-demo
```
